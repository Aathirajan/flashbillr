# Flashbillr (earlier admin panel)

Earlier version of the Flashbillr admin panel, a React + Vite web app that connects to the Flashbillr backend API.

## How to run

Prerequisites: Node.js and npm.

```bash
npm install
cp .env.example .env   # set VITE_API_BASE_URL (also VITE_NODE_ENV, VITE_DEBUG)
npm run dev       # start dev server
npm run build     # production build
npm run preview
npm run lint
```
